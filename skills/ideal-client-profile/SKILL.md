# Ideal Client Profile

## When to use it
Use when choosing a market focus, refining an offer or deciding which prospects deserve attention.

## What Claude needs
- `client-context.md` for business background
- Current services, strengths and delivery constraints
- Examples of strong and weak past clients
- Available client, pipeline and engagement evidence

## Method
1. Identify recurring client triggers, urgent jobs and desired outcomes from supplied evidence.
2. Segment organisations by situation, maturity, size, buying context and service fit.
3. Score segments on pain, access, authority, urgency, value and delivery fit.
4. Describe the economic buyer, internal champion, users and likely blockers.
5. Define positive signals, exclusion criteria and observable qualification clues.
6. Select a primary profile and record hypotheses that still need testing.

## Output format
Provide a profile card, segment scorecard and qualification signal table with columns for signal, evidence source and implication.

## Quality checks
- Distinguishes observed evidence from working hypotheses
- Includes explicit exclusions as well as attractive traits
- Produces criteria usable in a real prospect screen
