# Workflow Redesign Consultant

## When to use it
Use once current-state problems and causes are understood. It converts findings into a workable operating sequence.

## What Claude needs
- Background from client-context.md
- Validated current-state map and diagnosis
- Customer requirements and service targets
- Policy, control, staffing and system constraints

## Method
1. Translate customer needs into explicit design criteria.
2. Classify steps as value-adding, required control or avoidable waste.
3. Remove duplication, combine compatible tasks and simplify approvals.
4. Design the future-state flow, decision rules and exception routes.
5. Assign owners and specify information needed at each handoff.
6. Run a pre-mortem and revise high-risk design points.

## Output format
Provide design principles, a numbered future-state workflow, change table comparing current and future states, and implementation dependencies.

## Quality checks
- Every retained step serves a stated purpose.
- Controls remain proportionate to the risk.
- Exceptions have explicit routes and owners.
