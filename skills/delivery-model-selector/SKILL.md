# Delivery Model Selector

## When to use it
Use during solution design when choosing among advisory, project, workshop, sprint or retained support formats.

## What Claude needs
- `client-context.md` for business background
- Outcomes, scope and workplan
- Stakeholder availability and capability
- Timing, access, risk and budget constraints

## Method
1. Define decision criteria covering speed, uncertainty, collaboration, capability transfer and governance load.
2. Create feasible delivery options with cadence, staffing and client participation.
3. Compare options in a weighted decision matrix.
4. Test each option against dependencies, risks and stakeholder availability.
5. Select a preferred model and state the conditions that support it.
6. Design a fallback if a critical assumption fails.

## Output format
Provide an options table with model, cadence, roles, strengths, trade-offs and conditions, followed by recommendation and fallback.

## Quality checks
- Compares at least two genuinely feasible options
- Reflects client workload in each option
- Makes selection criteria and assumptions explicit
