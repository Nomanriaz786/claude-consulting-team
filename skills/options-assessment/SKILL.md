# Options Assessment

## When to use it
Use when debate is circling preferences and a structured comparison is needed to reach a defensible choice.

## What Claude needs
- client-context.md and the decision question
- Longlist of options and baseline option
- Constraints, criteria and stakeholder priorities
- Evidence, assumptions and non-negotiables

## Method
1. Confirm the decision boundary and include the do-nothing baseline.
2. Remove options that fail explicit minimum conditions, with reasons.
3. Define non-overlapping criteria and agree their relative importance.
4. Score the shortlist using evidence and document scoring rationale.
5. Run sensitivity and pre-mortem tests on the leading options.
6. Recommend a path with conditions, trade-offs and fallback triggers.

## Output format
Provide an option summary, criteria definitions, comparison matrix, sensitivity notes, recommendation and conditions. Show evidence beside each score.

## Quality checks
- Criteria do not predetermine the preferred option.
- Scores are consistent with the written evidence.
- The baseline, uncertainties and switching conditions are visible.
