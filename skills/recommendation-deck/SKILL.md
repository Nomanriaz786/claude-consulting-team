# Recommendation Deck

## When to use it
Use after analysis is complete and stakeholders need to understand, challenge and act on the proposed direction.

## What Claude needs
- client-context.md and audience profile
- Core question, analysis and recommendation
- Supporting exhibits and source notes
- Meeting objective, duration and desired decision

## Method
1. Write the governing thought as a single complete sentence.
2. Build a situation, complication, question and answer storyline.
3. Turn each slide title into a supported takeaway, not a topic label.
4. Select one exhibit or proof set for each major claim.
5. Present alternatives, trade-offs and implementation implications fairly.
6. Close with the decision, commitments, owners and next steps.

## Output format
Provide a slide-by-slide outline with columns for Slide, Takeaway Title, Key Content, Exhibit and Speaker Cue. Include an appendix plan.

## Quality checks
- Reading slide titles alone reveals the full argument.
- Each claim has relevant evidence or is labelled as judgement.
- The ending asks for a specific decision or commitment.
