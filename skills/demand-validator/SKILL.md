# Demand Validator

## When to use it
Use after identifying an opportunity but before a major launch, build or market entry commitment.

## What Claude needs
- Opportunity and target segment
- Business context from client-context.md
- Demand hypotheses and riskiest assumptions
- Available test channels, time and capacity

## Method
1. Define the demand claim and observable behaviour that would support it.
2. Rank assumptions by uncertainty and consequence using an assumption map.
3. Design the smallest ethical test for each critical assumption.
4. Set thresholds, comparison groups and stopping rules before testing.
5. Separate signals of attention, intent, commitment and repeat behaviour.
6. Specify how each result changes the next decision or test.

## Output format
Create an assumption register and test cards with hypothesis, audience, stimulus, measure, threshold, risk and next action.

## Quality checks
- Tests measure behaviour relevant to real adoption
- Thresholds are set before results are seen
- Test exposure and evidence strength are not overstated
