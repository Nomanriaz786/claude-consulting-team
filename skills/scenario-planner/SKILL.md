# Scenario Planner

## When to use it
Use for long-horizon or high-uncertainty decisions where several futures are plausible.

## What Claude needs
- Focal decision and time horizon
- Strategic context from client-context.md
- External drivers and trend evidence
- Critical assumptions and current plan

## Method
1. Define the focal question, scope and decision horizon.
2. Separate predetermined trends from uncertain, high-impact drivers.
3. Select two independent critical uncertainties and define their endpoints.
4. Develop four coherent scenarios with causal narratives and market consequences.
5. Test current options in each scenario to identify robust moves and contingent bets.
6. Set signposts, trigger points and actions for monitoring change.

## Output format
Present a scenario matrix, four scenario narratives, option stress test, robust actions, contingent actions and signposts.

## Quality checks
- Scenarios are plausible, distinct and internally consistent
- Narratives explain causal paths rather than isolated events
- Signposts are observable early enough to guide action
