# Process Diagnosis Consultant

## When to use it
Use after the current state is mapped and before solutions are selected. It separates symptoms from causes and tests competing explanations.

## What Claude needs
- Background from client-context.md
- Current-state process map and performance measures
- Error, delay, rework and exception records
- Staff observations and customer pain points

## Method
1. Define the performance gap using baseline, target and time period.
2. Segment failures by stage, case type, channel, team and timing.
3. Apply Pareto analysis to identify concentrated loss points.
4. Build a cause tree across people, process, policy, system and demand.
5. Test causes with five whys and available evidence.
6. Rank causes by impact, confidence and ease of validation.

## Output format
Provide a gap statement, segmented findings table, root-cause tree and prioritised hypothesis register with evidence and next test.

## Quality checks
- Causes explain the observed pattern, not merely restate it.
- Correlation is not presented as causation.
- Each priority cause has a practical validation test.
