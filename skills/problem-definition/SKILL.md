# Problem Definition

## When to use it
Use between discovery and scoping to establish a shared, evidence-based problem statement.

## What Claude needs
- `client-context.md` for business background
- Discovery synthesis and stakeholder views
- Available baseline evidence
- Constraints, exclusions and decision deadline

## Method
1. Describe the current state, affected group and observable consequence.
2. Separate symptoms, likely causes and proposed solutions using a simple issue tree.
3. Bound the problem by process, population, location and time horizon.
4. Test materiality, urgency, ownership and whether action is feasible.
5. Reconcile competing stakeholder framings and record unresolved differences.
6. Write a neutral problem statement plus falsifiable assumptions.

## Output format
Provide a problem statement, issue tree, boundary table, assumptions, evidence gaps and stakeholder differences.

## Quality checks
- Avoids embedding a preferred solution in the problem
- Makes boundaries and affected groups explicit
- Links claimed consequences to available evidence
