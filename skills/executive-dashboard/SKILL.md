# Executive Dashboard

## When to use it
Use for recurring oversight where leaders need signals for intervention rather than operational detail.

## What Claude needs
- client-context.md and executive priorities
- Outcomes, indicators, baselines and thresholds
- Current and historical performance data
- Owners, cadence and available data sources

## Method
1. Start from executive decisions and map each to a useful indicator.
2. Balance outcome, leading, delivery, risk and capacity measures.
3. Define calculation, source, owner, cadence and threshold for each measure.
4. Show trend and variance against baseline or target direction.
5. Pair every material exception with cause, impact and response.
6. Remove measures that do not change a decision or action.

## Output format
Provide an executive snapshot followed by a table with Indicator, Current Position, Trend, Threshold, Interpretation, Action, Owner and Data Date.

## Quality checks
- Measures reconcile to named and current sources.
- Status colours follow explicit thresholds.
- The dashboard distinguishes signal from normal variation.
