# Hypothesis Planner

## When to use it
Use after framing the problem and before research, interviews or analysis begin.

## What Claude needs
- The key decision and issue tree
- Background from client-context.md
- Current beliefs and assumptions
- Available data, people and research time

## Method
1. State a provisional answer for each priority issue-tree branch.
2. Express each hypothesis as a falsifiable claim with defined terms.
3. List supporting assumptions and the evidence that would confirm or reject them.
4. Set practical decision thresholds without inventing false precision.
5. Rank tests by decision impact, uncertainty, effort and evidence reliability.
6. Define how contradictory findings will update the working view.

## Output format
Create a hypothesis register with columns for claim, rationale, assumptions, test, evidence source, threshold, priority and status.

## Quality checks
- Every hypothesis can be disproved
- Tests address the claim rather than a convenient proxy
- Priorities reflect decision value and uncertainty
