Goal: Secure a decision and transfer an executable plan to owners.
Inputs: client-context.md, recommendation, evidence, constraints, target dates.
1. Run `options-assessment` on the available choices.
Write outputs/06-executive-delivery/options-assessment.md.
2. Run `decision-memo` on the preferred option.
Write outputs/06-executive-delivery/decision-memo.md.
3. Run `investment-case` using validated benefits and costs.
Write outputs/06-executive-delivery/investment-case.md.
Checkpoint: Human approves the recommendation and decision request.
4. Run `implementation-roadmap` on the approved decision.
Write outputs/06-executive-delivery/implementation-roadmap.md.
5. Run `milestone-plan` with named owners and dependencies.
Write outputs/06-executive-delivery/milestone-plan.md.
6. Run `benefits-realisation` to define measures and ownership.
Write outputs/06-executive-delivery/benefits-plan.md.
7. Run `client-handover` using all approved files.
8. Run `closeout-pack` to assemble the final record.
Final deliverable: outputs/06-executive-delivery/handover-pack.md.
