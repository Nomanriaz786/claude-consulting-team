Goal: Redesign a core process and prepare it for adoption.
Inputs: client-context.md, process records, performance data, staff input.
1. Run `process-mapping` on the current process.
Write outputs/04-operations-transformation/current-process-map.md.
2. Run `process-diagnosis` on the process map and data.
Write outputs/04-operations-transformation/process-diagnosis.md.
3. Run `bottleneck-removal` on the confirmed constraints.
Write outputs/04-operations-transformation/bottleneck-options.md.
Checkpoint: Human confirms root causes and design criteria.
4. Run `workflow-redesign` using approved criteria.
Write outputs/04-operations-transformation/future-workflow.md.
5. Run `role-clarity` for the redesigned workflow.
Write outputs/04-operations-transformation/role-clarity.md.
6. Run `standard-operating-procedures` for critical activities.
Write outputs/04-operations-transformation/operating-procedures.md.
7. Run `change-adoption` on the complete design.
Final deliverable: outputs/04-operations-transformation/operations-redesign-plan.md.
