Goal: Turn an initial prospect conversation into an approved proposal.
Inputs: client-context.md, prospect notes, known constraints, target decision date.
1. Run `discovery-call-prep`.
Write outputs/01-clients-engagements/discovery-call-prep.md.
2. Run `discovery-question-design` using the preparation file.
Write outputs/01-clients-engagements/discovery-questions.md.
3. Run `discovery-synthesis` after the call.
Write outputs/01-clients-engagements/discovery-synthesis.md.
4. Run `problem-definition` on the synthesis.
Write outputs/01-clients-engagements/problem-definition.md.
5. Run `engagement-outcomes` and `scope-boundary-design` in sequence.
Write outputs/01-clients-engagements/outcomes-and-scope.md.
Checkpoint: Human reviews facts, assumptions, outcomes, and scope.
6. Run `fee-setting` on the approved scope.
Write outputs/01-clients-engagements/fee-options.md.
7. Run `proposal-writer` using all approved files.
Final deliverable: outputs/01-clients-engagements/proposal.md.
