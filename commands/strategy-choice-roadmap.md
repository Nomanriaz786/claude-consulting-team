Goal: Convert an ambiguous growth question into a strategic roadmap.
Inputs: client-context.md, leadership question, available research, planning horizon.
1. Run `issue-tree` on the leadership question.
Write outputs/02-research-strategy/issue-tree.md.
2. Run `hypothesis-planner` using the issue tree.
Write outputs/02-research-strategy/hypothesis-plan.md.
3. Run `research-brief` to define evidence needs.
Write outputs/02-research-strategy/research-brief.md.
4. Run `evidence-synthesiser` on the collected evidence.
Write outputs/02-research-strategy/evidence-synthesis.md.
5. Run `growth-options` from the supported findings.
Write outputs/02-research-strategy/growth-options.md.
Checkpoint: Human reviews evidence strength, gaps, and options.
6. Run `strategic-choice` on the approved options.
Write outputs/02-research-strategy/strategic-choice.md.
7. Run `strategy-roadmap` on the selected direction.
Final deliverable: outputs/02-research-strategy/strategy-roadmap.md.
